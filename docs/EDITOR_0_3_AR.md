# محرر ريشة 0.3
0.3 تضيف أول بنية عملية لمحرر ريشة.

## شجرة العالم
العالم هو الجذر. يمكن إضافة كائنات تحته، تحديدها، حذفها وإعادة تسميتها.

## المفتش
المفتش يحرر الاسم والنوع والموقع والحجم والظهور للكائن المحدد.

## المعاينة
المعاينة ترسم الكائنات المرئية داخل العالم وتوضح الكائن المحدد.

## حفظ وفتح
ملفات العالم تستخدم الامتداد risha وتحفظ بيانات العالم والكائنات وخصائصها.

## البرمجة
محرر اللغة والمخرجات موجودان داخل المحرك. زر ترجمة وتشغيل يمرر النص إلى مترجم ريشة والآلة الافتراضية داخل العملية نفسها.
