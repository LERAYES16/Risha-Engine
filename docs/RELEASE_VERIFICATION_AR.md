# تقرير تحقق محرك ريشة 0.5

## البيئة

- Linux x86-64، GNU C++ 14.2.0، CMake، X11، وXvfb للاختبارات الرسومية الآلية.
- تم الحفاظ على بنية المصدر الحالية وتنسيقات `.risha` و`.rishaproject` و`.rishascript`.
- لم يتم بناء نسخة Windows أو تشغيلها في بيئة Windows فعلية.

## البناء والاختبارات

من مجلد `Risha Engine`:

```bash
cmake -S . -B build -DRISHA_BUILD_TESTS=ON
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
```

النتيجة: نجح البناء النظيف، ونجحت الاختبارات الأربعة `risha_core_tests` و`risha_script_tests` و`risha_scene_tests` و`risha_runtime_tests` (4/4). يتضمن اختبار Runtime تحميل مشهد المثال بأسماء عربية وتشغيل سكربت حركة يستخدم اسم «لاعب».

## تحقق واجهة Linux/X11

- تم تشغيل المحرر في Xvfb وانتظار انتهاء شاشة البداية.
- نُقر زر إنشاء مشروع جديد؛ أنشأ التطبيق `project.rishaproject` و`main.risha` في مجلد جديد.
- نُقر زر «＋ لاعب» ثم زر «تشغيل». ظهرت نافذة X11 ثانية مستقلة بعنوان «ريشة — تشغيل اللعبة» مع بقاء المحرر مفتوحاً.
- أُرسل حدث ضغط سهم الاتجاه إلى نافذة اللعب ثم رُصد تغير في 1101 عينة بكسل من المشهد، ما يثبت أن الإطار تغيّر بعد الإدخال.
- نُفذ مسار واجهة إنشاء السكربت، وتحقق وجود `scripts/script_2.rishascript` وحفظ النص الابتدائي.
- تم بناء المحرر وإعادة تشغيل الاختبارات بعد إضافة موضع المؤشر بالنقر.

## الوظائف المنفذة في نافذة اللعب

- نافذة منفصلة عن المحرر مع حلقة تحديث ورسم.
- تحريك الشخصية المختارة عبر الأسهم وWASD وZQSD عندما لا يعرّف سكربت اللاعب الحركة بنفسه.
- تنفيذ السكربتات المرتبطة بالمشهد في الإطارات مع واجهات الوقت والإدخال والحركة الموثقة في Runtime.
- رسم أولي للأشكال واللاعب والأرض، وليس نظام خامات أو رسوم متحركة متكاملاً.
- إغلاق النافذة بـEsc أو زر «إيقاف».

## الحدود المعروفة

- لا تزال الفيزياء التصادمية الكاملة والصوت والخامات PNG/JPEG والرسوم المتحركة المتقدمة والكاميرا المتحركة غير مكتملة.
- لا يدعم محرر السكربت تحديد النص أو التراجع والإعادة أو التلوين النحوي أو الإكمال التلقائي؛ التعديلات الجديدة تطبق عند إيقاف اللعبة وحفظ السكربت ثم التشغيل مجدداً.
- التحقق الرسومي تم في Xvfb؛ لم يتم اختبار جميع مديري النوافذ أو دقات الشاشة أو تخطيطات لوحة المفاتيح الفعلية.
- لم يتم التحقق من Windows.
- اجتياز الاختبارات لا يثبت خلو البرنامج من جميع العيوب.
