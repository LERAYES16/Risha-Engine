# سجل التغييرات — محرك ريشة

## تحسينات واجهة Linux المدمجة في إصدار 0.5

- إظهار أسماء إنجليزية بجانب أسماء الأزرار العربية في القائمة الرئيسية وشريط الأدوات لتظل الأسماء مقروءة عندما لا تتوفر معالجة تشكيل العربية في خط X11.
- توحيد هندسة أزرار القائمة الرئيسية المرئية مع مناطق النقر، وجعل مواضعها تتكيف مع حجم النافذة.
- تمديد شاشة الإقلاع إلى نحو ست ثوانٍ وربط تقدم كتابة الاسم بتقدم رسم الريشة كي يكتمل الاثنان معاً.
- تحسين شكل الريشة بخط ساق مركزي متعدد الطبقات، وزغب أكثر كثافة، ولمعات دقيقة، وقاعدة قلم/قصبة واضحة.
- تخزين ألوان الرسم مؤقتاً لتقليل التخصيصات المتكررة أثناء الإطارات.
- التحقق من بناء Linux واختبارات CTest الأربعة، وتجربة النقر الفعلي على زر إنشاء المشروع داخل Xvfb.


## 0.4 — إصلاحات واستقرار

- تحسين إنشاء أسماء الكائنات: الاسم الافتراضي الآن يعتمد على النوع ويزداد بوضوح عند التكرار.
- الحفاظ على الاسم الذي يختاره المستخدم مع بقاء المعرّف الداخلي ثابتًا.
- تشديد التحقق عند تحميل ملفات `.risha` لمنع المعرّفات المكررة والعلاقات الدائرية والبيانات الرقمية غير الصالحة.
- إصلاح اختبار كان يستخدم مؤشرًا قد يصبح غير صالح بعد إعادة تخصيص ذاكرة القائمة.
- الحفاظ على توافق تحميل ملفات مشاهد 0.3.
- ما زالت أنظمة الرسومات والصوت والفيزياء والإدخال وRuntime المتقدم وغيرها قيد الاستكمال، ولا تُقدَّم كميزات مكتملة.

## 2026-09-15 — إصلاح المحرر 0.4

- استبدال أسماء الكائنات غير الواضحة بنظام أسماء بشرية وفريدة، مع دعم الاسم الذي يكتبه المستخدم.
- إضافة نافذة حقيقية لإضافة الكائن مع أنواع محددة.
- إضافة إعادة تسمية مباشرة من شجرة العالم عبر النقر المزدوج أو F2.
- إضافة قائمة زر أيمن لشجرة العالم.
- إضافة نسخ الكائنات مع أسماء فريدة بدون حلقة تسمية.
- إضافة خصائص الدوران والمقياس وZ والمورد وانعكاس المحاور والكاميرا إلى المفتش.
- إضافة مساحة عرض تفاعلية للتحديد والسحب والتكبير.
- إضافة عرض فعلي لملفات PNG وJPG وJPEG وBMP في مساحة العرض عند ربطها كمورد صورة باستخدام Windows GDI+.
- إضافة متصفح موارد يفحص مجلد العالم ويدعم التحديث والنقر المزدوج لربط المورد.
- إصلاح بنية تحديث المخرجات لتحديث النص دفعة واحدة وتقليل الوميض وفقدان موضع التمرير.
- إضافة تصنيفات للمخرجات ومصدر العملية.
- تحويل التعليمات إلى نافذة قابلة لتغيير الحجم والتمرير بدلاً من MessageBox ثابت.
- تحسين التخطيط ليعيد توزيع الأدوات عند تصغير النافذة، مع حد أدنى مناسب للمحرر.
- إصلاح تسمية النسخ المتكررة واختبارها حتى النسخة الثالثة.


### 0.4 إعادة بناء واجهة البداية

- إضافة أزرار قناة يوتيوب وصفحة itch.io.
- تحسين تحديث المخرجات لتقليل الوميض وإعادة الرسم غير الضرورية.
- تحسين أسماء الكائنات عند التحميل ومنع ظهور المعرّفات الداخلية كأسماء للمستخدم.

- نص الإقلاع يظهر تدريجياً بصيغة `Risha Engine -محرك ريشة`.

- إضافة إظهار/إخفاء المخرجات من زر `إخفاء المخرجات` و`إظهار المخرجات`.
- إصلاح مسارات الصور والموارد النسبية لتعمل من مجلد المشروع.
- إضافة زر اختيار مورد من الملفات وربطه بخاصية المورد.
- تحسين نافذة إضافة الكائنات ومعالجة الإدخال النصي بالكامل.

- إضافة اختبارات للميزات الجديدة.

## 0.5 — تحسينات الاستقرار

- ربط نقرات قائمة البداية بإجراءات إنشاء المشروع وفتح المثال والاعتمادات والخروج.
- جعل تحميل إعدادات المشروع يرفض الأرقام غير الصالحة، وأحجام النوافذ غير المنطقية، ومعدل الإطارات غير المقبول، وأسماء أفعال الإدخال المكررة بأمان.
- إضافة اختبارات لإعدادات مشروع مشوهة.
- تحديث README إلى العربية والإنجليزية مع متطلبات التثبيت والبناء والاختبار والتشغيل والإزالة وحدود الميزات الفعلية.

- إضافة مسار نصوص اختياري عبر Pango/Xft وقت التشغيل مع تشكيل العربية، وخط X11 احتياطي.

- تحسين هندسة زغب الريشة وانحناء الساق واللمعات.


## 0.5 — مراجعة الاستقرار قبل التسليم

- توحيد رقم الإصدار الظاهر في CMake وواجهة Linux واسم النافذة مع الإصدار المطلوب 0.5.
- زيادة المسافة بين مساحة العرض ولوحة المخرجات لمنع تداخل سطر وصف مساحة العرض مع اللوحة عند ارتفاع النافذة المعتاد.
- منع إنشاء مشروع جديد من الكتابة فوق مجلد `risha_project` موجود؛ تُختار لاحقة رقمية عند وجود المجلد.
- جعل الحفظ يبلّغ بوضوح إذا تعذر حفظ إعدادات المشروع بعد حفظ المشهد.
- إزالة افتراض أن اللاعب دائماً هو الكائن ذو المعرّف 2؛ يجري العثور على كائن `Player` ذي السكربت بالاسم.
- إضافة تحرير أساسي للسكربت المحدد عبر لوحة المفاتيح: إدخال نص UTF-8، والحذف، والتنقل، والأسطر الجديدة، والمسافة البادئة، والحفظ المستقل عبر `Ctrl+S`.
- إعادة بناء Linux وتشغيل الاختبارات الآلية وتصوير واجهتي القائمة والمحرر داخل Xvfb.
- لا تزال واجهة Linux محدودة: محرر السكربت يدعم التحرير الأساسي لكنه لا يدعم التحديد أو التراجع أو الإكمال التلقائي، والتشغيل ليس نافذة لعبة مستقلة، ونسخة Windows لم تُختبر في بيئة Windows فعلية.

## تحديث استقرار مدير المشاريع — 0.5
- أضيفت شاشة مشاريع رئيسية بتصميم داكن مستقل، وبطاقات قابلة للتفاعل مع تمييز التحويم وحركة دخول خفيفة ولمسات زرقاء متحركة.
- تعرض الشاشة المشاريع المكتشفة تلقائياً والمشاريع الأخيرة المحفوظة محلياً في `~/.local/share/risha-engine/recent-projects.txt`.
- أضيف فتح المشروع من بطاقته، وتحديث القائمة عبر R، وتمرير البطاقات بعجلة الفأرة، واختيار مجلد المشروع عبر Zenity عند توفره.
- أصبحت المشاريع الجديدة تُنشأ في `~/Documents/Risha Projects` مع تجنب استبدال المجلدات الموجودة.
- لم تتغير صيغة ملفات `.risha` و`.rishaproject` و`.rishascript`.


## 0.5 — إصلاحات واجهة ومشروع جديد

- جعل إنشاء المشروع ينشئ مشهداً فارغاً بدلاً من تجهيز عناصر المثال.
- التحقق من نجاح حفظ إعدادات المشروع والمشهد قبل اعتبار الإنشاء ناجحاً.
- إضافة أزرار عربية لإضافة مربع ولاعب وكائن جديد من المحرر.
- إضافة زر واضح لفتح أو إنشاء سكربت للكائن المحدد، مع ملف ابتدائي عربي قابل للتحرير.
- توسيع مساحة السكربت وإظهار مؤشر الكتابة وتعليمات الحفظ.
- تفعيل إدخال UTF-8 عبر XIM في واجهة لينكس.
- إضافة حالات تحويم متحركة لأزرار المحرر وبطاقات شاشة البداية.
- إظهار عنوان «محرك ريشة» حرفاً بعد حرف، مع تثبيت حافة النص العربي أثناء الكشف.
- جعل التشغيل يختار السكربت المحدد أو سكربتاً مرتبطاً بكائن آخر دون الاعتماد على اسم `Player`.
- إضافة اختبار للعبارة العربية الافتراضية المستخدمة عند إنشاء السكربت.

- إضافة زر «العودة إلى المشاريع» من المحرر، مع حفظ التعديلات قبل الرجوع وتحديث قائمة المشاريع.
- إصلاح إظهار المخرجات بعد تشغيل السكربت، وتعديل موضع شريط الحالة لمنع قص النص أسفل النافذة.

- إضافة تمايل خفيف متغير للريشة ولمعة ذهبية دقيقة على الساق وقاعدة الريشة أثناء الكشف.


## 0.5 — نافذة لعب مستقلة وإصلاح التفاعل

- إضافة نافذة تشغيل منفصلة عن المحرر؛ تبقى نافذة المحرر مفتوحة أثناء تجربة اللعبة.
- إضافة تحديث إطار اللعبة ورسم المشهد في الزمن الحقيقي مع شخصية أولية وأشكال وأرض.
- دعم الحركة عبر الأسهم وWASD وZQSD، مع إغلاق نافذة اللعب عبر Esc أو زر الإيقاف.
- تنفيذ السكربتات المرتبطة في حلقات الإطارات وتوفير قيم الإدخال والوقت ودلتا الإطار للغة ريشة سكربت.
- تحويل أسماء عناصر مشهد المثال إلى العربية، وتحديث سكربته ليستخدم اسم اللاعب العربي.
- إضافة أزرار عربية لإنشاء مخلوق وأرض، مع رسم أولي لكل منهما.
- إصلاح النقر داخل لوحة السكربت لوضع المؤشر؛ لم يعد النقر يعيد تحميل السكربت ويمنع اختيار موضع الكتابة.
- اختبار البناء النظيف والاختبارات الآلية الأربعة، واختبار واجهة X11 يفتح مشروعاً فارغاً ويضيف لاعباً ويفتح نافذة لعب مستقلة؛ تغيّرت بكسلات المشهد بعد ضغط سهم الاتجاه للتحقق من الحركة.
- لم يتم اختبار Windows، ولم تكتمل بعد الفيزياء التصادمية والصوت والخامات والرسوم المتحركة أو أدوات التحرير المتقدمة.
