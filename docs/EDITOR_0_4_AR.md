# محرر ريشة 0.4 على Linux

عند التشغيل تظهر شاشة إقلاع سوداء ترسم الريشة تدريجياً ثم تكتب اسم المحرك أثناء التحميل.

من القائمة الرئيسية:

- `N` إنشاء مشروع تجريبي محلي.
- `O` فتح المثال.
- `D` فتح `examples/demo.risha`.
- `Enter` فتح المثال بسرعة.
- `Esc` خروج.

داخل المحرر:

- `Ctrl+S` حفظ المشهد.
- `F5` تشغيل تجربة Runtime.
- `F6` إيقاف Runtime.
- `F2` تبديل منطقة Risha Script والمخرجات.
- `Ctrl+N` إنشاء Sprite.
- الأسهم تحرك الكائن المحدد إذا لم يكن مقفلاً.
- السحب بالزر الأيسر يحرك الكائن غير المقفول.
- الزر الأيمن يعرض حالة قائمة الكائنات في شريط الحالة.

المشهد يحفظ أسماء الكائنات ومعرفاتها وخصائصها الأساسية ومسارات الموارد والسكربت والسرعة والجاذبية والكاميرا والتصادم والصوت والشفافية والقفل.
