# لغة ريشة 0.2 — الإصدار الأول

لغة ريشة في 0.2 هي بداية صغيرة جدًا للغة عربية أصلية داخل المحرك. لا تعتمد الترجمة على Python أو مترجم خارجي أو ملف تنفيذي خارجي.

## أول الكلمات

`اطبع` لطباعة قيمة.

`عرّف` لإنشاء متغير.

`توقف` لإيقاف التنفيذ.

`#` لبداية تعليق.

## القيم

النص يكتب بين علامتي اقتباس:

`"مرحبا"`

الأرقام الصحيحة والعشرية مدعومة:

`42`

`3.14`

يمكن استخدام أسماء متغيرات عربية أو لاتينية:

`الاسم`

`النتيجة`

`score`

## الجمع

الأرقام تجمع حسابيًا:

`اطبع 20 + 22`

النصوص والقيم يمكن جمعها كنص:

`اطبع "ريشة" + " 0.2"`

## مثال كامل

```text
# أول برنامج بلغة ريشة
عرّف الاسم = "ريشة"
عرّف الرقم = 20
اطبع "مرحبا من محرك ريشة!"
اطبع الاسم + " — الإصدار 0.2"
اطبع الرقم + 22
```

## كيف يعمل البناء

عند الضغط على **ترجمة وتشغيل** داخل محرر ريشة:

1. يقرأ المحرك النص العربي.
2. يحوله إلى تعليمات داخلية بسيطة تسمى Bytecode.
3. يشغل هذه التعليمات داخل آلة ريشة الافتراضية.
4. يرسل ناتج البرنامج إلى لوحة **المخرجات** داخل المحرر.
5. عند وجود خطأ، يظهر رقم السطر ورسالة الخطأ بالعربية.

لا يتم تشغيل `g++` أو `cmake` أو أي برنامج خارجي لترجمة لغة ريشة.

## حدود 0.2

هذه بداية اللغة وليست اللغة النهائية. لا توجد بعد شروط أو حلقات أو دوال أو كائنات أو ملفات أو مكتبات أو نظام أنواع متقدم. ستتم إضافتها لاحقًا بعد تثبيت أساس اللغة واختبارها.
