# لغة ريشة 0.4

لغة ريشة هي لغة عربية خفيفة داخل محرك ريشة. تدعم المتغيرات والأرقام والنصوص والقيم المنطقية والحساب والمقارنة والشروط والحلقات واستدعاء دوال المكتبة ودوال المحرك.

## المتغيرات

```text
عرّف السرعة = 120
غيّر السرعة = السرعة + 10
عرّف الاسم = "ريشة"
```

## الشروط والحلقات

```text
إذا السرعة > 100
    اطبع "سريع"
وإلا
    اطبع "هادئ"
نهاية

كرر 3
    اطبع "محاولة"
نهاية

طالما السرعة > 0
    غيّر السرعة = السرعة - 1
نهاية
```

## الدوال

```text
اطبع جذر(81)
اطبع مطلق(-20)
اطبع تقريب(2.7)
```

الدوال الرياضية الفعلية هي `مطلق` و`جذر` و`جيب` و`جيب_تمام` و`مستقيم` و`تقريب` و`أرضية` و`سقف`.

## دوال المحرك

عند التشغيل عبر Runtime يمكن للسكربت استعمال `دلتا()` و`وقت()` و`زر_مضغوط()` و`زر_مستمر()` و`حرك()` و`موضع_س()` و`موضع_ص()` و`سرعة()`.

مثال:

```text
عرّف السرعة = 120
إذا زر_مستمر("حركة_يمين")
    حرك("لاعب", السرعة * دلتا(), 0)
نهاية
اطبع موضع_س("لاعب")
```

استدعاء دالة المحرك يمكن أن يكون تعليمة مستقلة. هذا يسمح بعمليات مثل `حرك(...)` دون طباعة قيمة الإرجاع.

الأسماء العربية والإنجليزية Unicode مدعومة، والنصوص Unicode محفوظة كما هي.


## استخدام السكربت في محرر 0.5

1. أنشئ مشروعاً فارغاً من القائمة الرئيسية.
2. أضف كائناً من أزرار «＋ مربع» أو «＋ لاعب» أو «＋ كائن».
3. حدّد الكائن، ثم اضغط «السكربت». ينشئ المحرر ملفاً داخل `scripts/` ويربطه بالكائن.
4. انقر منطقة السكربت للكتابة. استخدم `Ctrl+S` أو زر «حفظ».
5. استخدم `F5` أو «تشغيل» لتنفيذ السكربت المحدد، ثم اقرأ رسائل التنفيذ في «المخرجات».

مثال عربي قابل للتنفيذ:

```text
عرّف السرعة = 120
اطبع "مرحباً من ريشة"
اطبع السرعة + 30
```

الكلمات المدعومة تشمل `عرّف` و`غيّر` و`اطبع` و`إذا` و`وإلا` و`طالما` و`كرر` و`نهاية` و`توقف`، كما يمكن استخدام `و` و`أو`. لا تزال كتابة السكربت نصية أساسية؛ التحديد المتقدم، والتراجع والإعادة، والتلوين النحوي، والإكمال التلقائي غير متاحة بعد.
