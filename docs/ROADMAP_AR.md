# خارطة طريق ريشة

## 0.1
نافذة، حلقة، زمن، سجل، وإغلاق آمن.

## 0.2
لغة ريشة الأولى ومترجم وآلة افتراضية ومخرجات داخل المحرك.

## 0.3
محرر العالم، شجرة العالم، المفتش، المعاينة، وحفظ المشهد.

## 0.4
تقوية نموذج المشهد، versioning، Unicode، أساس بيانات Transform والموارد والكاميرا والتصادم والصوت، وتحسين تجربة المحرر دون إضافة واجهات مزيفة.

## بعد 0.4
الأولوية هي إنهاء أنظمة 2D واحداً تلو الآخر من البداية إلى النهاية: الموارد والصور، Renderer 2D، Runtime، Input، Collision/Physics، Script API، Audio، Animation، UI، ثم أدوات التصدير. لا توجد خطة لإضافة 3D قبل استقرار أساس 2D.
