# معمارية محرك ريشة 0.4

## الهدف

0.4 لا تعيد كتابة 0.3. تم الحفاظ على النواة والمترجم ونموذج Scene وطبقة Win32، ثم توسعت بيانات المشهد وأصبحت الصيغة versioned.

## الطبقات

### النواة

`Time` يقيس الزمن باستخدام `steady_clock`. `Logger` يرسل الرسائل إلى CMD، ويستخدم Windows Unicode APIs عند العمل في Windows.

### العالم

`Scene` يملك الكائنات. لكل كائن معرف داخلي ثابت، اسم قابل للتغيير، أب، نوع، Transform، ترتيب Z، لون، مورد، سكربت، وسياقات أولية للسرعة والجاذبية والكاميرا والتصادم والصوت.

### صيغة المشهد

الملف يبدأ بـ `RISHA_SCENE_0_4`. النصوص Unicode تُخزن بترميز آمن خاص بريشة، وليس بتنسيق محرك آخر. قارئ 0.4 يستطيع قراءة ملفات 0.3 ويضع القيم الجديدة على defaults.

### اللغة

المترجم يحول النص إلى تعليمات داخلية، ثم تنفذها الآلة الافتراضية. لا يتم استدعاء GCC أو Python عند الضغط على ترجمة وتشغيل.

### المحرر

المحرر Windows أصلي. شجرة العالم والمفتش والمعاينة ومحرر اللغة والمخرجات منفصلة منطقياً. جميع النصوص الظاهرة للمستخدم عربية أولاً.

## قاعدة التطوير

لا توجد واجهة لنظام لم يُنفذ. عندما يصبح Sprite أو الفيزياء أو Input أو Runtime نظاماً مكتملاً سيتم ربطه بالمحرر وبصيغة `.risha` والاختبارات معاً.
