# Risha-Engine
A lightweight fully Arabic Game Engine made by me and open source, it's still in development so you might find some bugs or glitches
Right Now I'm in v0.4, and when i reach v1.0 it will be a fully working 2d Arabic game engine, At that time, I will try by myself to create a 2d game, you can now take the .zip file to test out the latest version i work on it, or to upgrade it to be more powerful and simple.
