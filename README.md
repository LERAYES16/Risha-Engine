# Risha Engine 0.5 / محرك ريشة 0.5

**صغير، سريع، حر في الإبداع.**

محرك ألعاب ثنائي الأبعاد خفيف مكتوب بلغة C++17، واجهته ولغة برمجته عربية بالكامل. المطوّر: **Khalil Riyad — LERAYES16**.
Risha Engine is a lightweight Arabic-first 2D engine in C++17. Formats: `.risha`, `.rishaproject`, `.rishascript`.

## البناء والتشغيل / Build & run

Linux (Debian / Ubuntu / Mint):

```bash
sudo apt install build-essential cmake libx11-dev
./build.sh            # يبني ويختبر ويشغّل المحرر
./build.sh --no-run   # بناء واختبار فقط
```

Windows (MinGW-w64 أو Visual Studio مع CMake): شغّل `build.bat`. المخرج: `build\risha_editor.exe`.

لا حاجة لأي مكتبة نصوص أو خطوط خارجية: الخط العربي (مجموعة جزئية من DejaVu Sans، ترخيص حر) مضمّن، والتشكيل العربي وترتيب الاتجاهين مبنيان داخل المحرك، فيعمل العربي على Linux وWindows بلا Pango أو Xft أو HarfBuzz.

خيارات: `risha_editor --demo` يفتح اللعبة التجريبية مباشرة، و`--demo-play` يفتحها ويشغّلها.

## ما الجديد في 0.5

- **شاشة البداية:** ريشة واقعية تُرسم تدريجيًا (ساق مقوّس، مئات الزغيبات المنحنية غير المتماثلة، لمعات، قاعدة) بينما يُكتب «Risha Engine - محرك ريشة» حرفًا حرفًا مع شريط تحميل.
- **حركات الأزرار:** تلوّن وتوهج عند المرور، ضغط مرئي، وموجة ضغط عند النقر، في القائمة الرئيسية والمحرر.
- **القائمة الرئيسية:** مشروع جديد، لعبة تجريبية، فتح مشروع، المشاريع الأخيرة.
- **المحرر:** شجرة كائنات، لوحة خصائص قابلة للتعديل (الاسم، س، ص، العرض، الارتفاع، الجاذبية، النص، نوع الجسم، اللون، الظهور، القفل)، سحب وتغيير حجم، تكبير بالعجلة وتحريك بالزر الأوسط، تراجع/إعادة، تكرار، حفظ تلقائي عند الخروج، محرر سكربت مع أرقام أسطر وتدقيق فوري، ولوحة مخرجات.
- **نافذة اللعبة:** زر «تشغيل» (أو F5) يفتح نافذة مستقلة؛ Esc يغلقها. الحركة بـ A/D أو Q/D (لوحات AZERTY) أو الأسهم، والقفز بالمسافة.
- **اللعبة التجريبية:** كتلة تتحرك يمينًا ويسارًا وتقفز فوق أرض (`examples/demo_game`).
- **العربية على Linux:** إدخال عربي عبر XIM مع بديل مباشر من رموز لوحة المفاتيح، واختصارات Ctrl تعمل حتى مع لوحة عربية.
- **المحرك:** فيزياء AABB (ثابت/متحرك/بلا)، حركة بدقة أقل من بكسل، كاميرا، نص، إنشاء وحذف كائنات أثناء اللعب.
- **لغة ريشة:** دوال (`دالة`/`ارجع`) وتكرار (`طالما`/`كرر`/`اخرج`/`استمر`) و`وإلا إذا` و`و`/`أو`/`ليس` والمقارنات النصية و`+=` وأخواتها، متغيرات `عام` تبقى بين الإطارات، أرقام عربية، ورسائل أخطاء برقم السطر.
- **إصلاحات:** القفز كان يعمل بشكل متقطع بسبب فقدان حالة «على الأرض»، تحقق صارم عند تحميل المشاهد والمشاريع، مسارات عربية آمنة على النظامين، ووميض المحرر أُزيل بإعادة رسم كاملة من مخزن مؤقت.

## الاختصارات

Ctrl+S حفظ · Ctrl+Z تراجع · Ctrl+Y إعادة · Ctrl+D تكرار · Delete حذف · F5 تشغيل · F6 إيقاف · F1 تعليمات

## حدود صريحة

- لم يُجرَّب البناء على Windows في بيئة Windows فعلية (كُتبت طبقة Win32 لكنها غير مُتحقَّق منها). تحقّق منه عبر `build.bat`.
- التحقق على Linux تم عبر Xvfb واختبارات CTest الستة.
- لا خامات صور، ولا صوت، ولا رسوم إطارية، ولا تحديد نص أو حافظة في المحرر، ولا بنية أب/ابن في الإحداثيات (إحداثيات الكائنات مطلقة).
- مبني على 0.5 دون تغيير رقم الإصدار.
